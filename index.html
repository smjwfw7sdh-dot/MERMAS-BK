📖 Manual rápido – LÚPICA

Cómo registrar una merma

  1. Selecciona la Tienda
  2. Revisa Fecha y Hora (se cargan solas)
  3. Escribe tu nombre en Responsable
  4. Confirma el Turno
  5. Toca la Categoría → elige Producto → cantidad → motivo
  6. Presiona Registrar Fila

Modo Gerente (PIN tienda)

  • PIN predeterminado por tienda: 2026
  • Cada tienda puede crear su propio PIN
  • Con modo gerente puedes exportar, enviar resumen y vaciar historial
  • Filtra por tienda para ver el waste mensual de cada local

Datos
