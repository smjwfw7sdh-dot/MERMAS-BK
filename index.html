📖 MANUAL RÁPIDO – Control de Mermas BK

Cómo registrar una merma:

  1. Abre la página
  2. Selecciona la Tienda (se guarda sola)
  3. Revisa Fecha y Hora (ya vienen cargadas)
  4. Escribe tu nombre en Responsable
  5. Confirma el Turno (se llena solo)
  6. Si eres Gerente/Admin, marca el checkbox de autorización
  7. Toca la Categoría
  8. Elige el Producto
  9. Escribe la Cantidad
  10. Selecciona el Motivo
  11. (Opcional) Escribe un detalle en Justificación
  12. Presiona Registrar Fila

¿Qué es cada campo?

  • Tienda → Local donde ocurrió la merma
  • Fecha / Hora → Cuándo ocurrió la merma
  • Responsable → Quién está registrando
  • Turno → AM / PM / Trasnoche
  • Categoría → Tipo de producto
  • Producto → Qué se botó
  • Cantidad → Cuánto se botó
  • Motivo → Por qué se botó
  • Justificación → Detalle extra (opcional)

Panel Lupa (nuevo):

  • Base de cálculo → Elige Venta del período o Costo Ideal
  • Valor base → Escribe el número que aparece en la Lupa real
  • % Merma → Se calcula solo con las mermas registradas
  • Dif Total % → Cópialo de la Lupa de Inventario Help

Solo Gerentes / Administradores autorizados pueden exportar a Excel y vaciar el historial.

Los datos se guardan automáticamente en este computador.
